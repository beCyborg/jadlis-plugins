# Детект состояния — пробы машины

Состояние определяется **пробами машины, а не словами пользователя**. Человек искренне
считает, что «батч 2 сделан», когда открыл Obsidian и создал папку. Проба этого не
подтвердит — и правильно.

## Один блок

Подставь вместо `{VAULT_PATH}` реальный путь (он дан в SKILL.md) и выполни **одним**
Bash-вызовом. Блок ничего не меняет — только читает.

```bash
V="{VAULT_PATH}"
P="$HOME/Library/Containers/app.spokenly/Data/Library/Preferences/app.spokenly.plist"

# ── Батч 1: Spokenly настроен ──────────────────────────────────────────────
b1=нет
if [ -f "$P" ]; then
  mp=$(plutil -extract mainPrompt      raw -o - "$P" 2>/dev/null)
  ap=$(plutil -extract aiProviders     raw -o - "$P" 2>/dev/null | base64 -d 2>/dev/null \
        | python3 -c 'import json,sys;print(len(json.load(sys.stdin)))' 2>/dev/null)
  wr=$(plutil -extract wordReplacements raw -o - "$P" 2>/dev/null | base64 -d 2>/dev/null \
        | python3 -c 'import json,sys;print(len(json.load(sys.stdin)))' 2>/dev/null)
  [ -n "$mp" ] && [ "${ap:-0}" -ge 2 ] 2>/dev/null && [ "${wr:-0}" -ge 1 ] 2>/dev/null && b1=да
fi
echo "БАТЧ1 закрыт=$b1 промпт_символов=${#mp} провайдеров=${ap:-0} замен=${wr:-0}"

# ── Батч 2: скелет vault + первая дневная заметка ──────────────────────────
cl=нет; [ -f "$V/CLAUDE.md" ] && cl=да
dn=$(ls "$V/Периоды/День/"*.md 2>/dev/null | wc -l | tr -d ' ')
b2=нет; [ "$cl" = да ] && [ "${dn:-0}" -ge 1 ] && b2=да
echo "БАТЧ2 закрыт=$b2 CLAUDE.md=$cl дневных_заметок=${dn:-0}"

# ── Батч 3: смысл жизни + метрики + цели квартала ──────────────────────────
sm=нет; [ -f "$V/Смысл жизни.md" ] && sm=да
mt=$(command grep -rl '^type: metric$' "$V/Потребности" 2>/dev/null | wc -l | tr -d ' ')
gl=$(ls -d "$V/Цели/"*Q*/ 2>/dev/null | while read -r d; do ls "$d"*.md 2>/dev/null; done | wc -l | tr -d ' ')
b3=нет; [ "$sm" = да ] && [ "${mt:-0}" -ge 10 ] && [ "${gl:-0}" -ge 2 ] && b3=да
echo "БАТЧ3 закрыт=$b3 смысл_жизни=$sm метрик=${mt:-0} целей_квартала=${gl:-0}"

# ── Батч 4: плагин стоит + есть боевые прогоны ─────────────────────────────
pg=нет; claude plugin list 2>/dev/null | command grep -q 'jadlis-research' && pg=да
rp=$(ls "$V/Знания/Ресерчи/"*.md 2>/dev/null | wc -l | tr -d ' ')
vd=$(ls "$V/AI/verif/"*verdict.md 2>/dev/null | wc -l | tr -d ' ')
b4=нет; [ "$pg" = да ] && [ "${rp:-0}" -ge 2 ] && [ "${vd:-0}" -ge 1 ] && b4=да
echo "БАТЧ4 закрыт=$b4 плагин=$pg отчётов=${rp:-0} вердиктов=${vd:-0}"

# ── Журнал (только «где я внутри батча», не «закрыт ли он») ────────────────
J="$V/Система/Передача/состояние.md"
[ -f "$J" ] && echo "ЖУРНАЛ есть: $(command grep -m1 '^батч:' "$J" 2>/dev/null)" || echo "ЖУРНАЛ отсутствует"
```

## Таблица критериев

| Батч | Проба | «Закрыт», если |
|---|---|---|
| 1 | `plutil` по плисту Spokenly | есть `mainPrompt` (непуст), `aiProviders` ≥ 2, `wordReplacements` ≥ 1 |
| 2 | `CLAUDE.md` + `Периоды/День/*.md` | файл есть **и** ≥ 1 дневная заметка |
| 3 | `Смысл жизни.md` + метрики + цели | все три: файл есть, метрик ≥ 10, целей квартала ≥ 2 |
| 4 | `claude plugin list` + артефакты | плагин установлен **и** отчётов ≥ 2 **и** вердиктов ≥ 1 |

## Как читать результат

- `mainPrompt` пуст → человек поставил Spokenly, но промпт-корректор не перенёс. Батч 1 не закрыт.
- Батч 2 не закрыт при существующем `CLAUDE.md` → скелет разложен, но вечерний ритм не начался.
  Это самый частый провал: система есть, пользоваться ею не начали.
- Метрик 4 из 10 → интервью идёт, но не дошло до конца. Это «внутри батча 3», а не «батч 3 закрыт».
- Батч 4: плагин стоит, отчётов 0 → установка была, боевых прогонов не было. Не закрыт.

## Расхождение с журналом

Журнал `Система/Передача/состояние.md` отвечает **только** на «где я внутри батча».
На вопрос «закрыт ли батч» отвечают пробы.

Журнал говорит «батч 3 закрыт», пробы — нет: перепиши журнал по пробам и скажи об этом
**одной строкой**, без разбирательства, — например: «Журнал говорил, что батч 3 закрыт,
но метрик 4 из 10 — поправил журнал по факту».

## Единственное послабление

`verif` штатно работает на **двух провайдерах из трёх**. Если пользователь показывает, что
Grok или Codex буксует, а вердикт при этом получен — батч 4 не блокируется. Проба этого не
видит (вердикт есть вердикт), но при разборе жалоб держи это в голове и не отправляй
чинить третьего провайдера как условие закрытия.
